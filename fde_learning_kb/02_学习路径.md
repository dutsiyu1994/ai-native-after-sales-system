# 2. 学习路径（8周）

**总原则**：先会「看见数据」→ 再会「改数据形态」→ 再「接通外部服务」→ 再「RAG/Agent」→ 最后「用 Eval 证明有效」。

每天 20—60 分钟；每周约 **5 个学习日 + 1 个复习/项目日**。

---

## 阶段总览

| 周次 | 阶段名 | 阶段目标（可验证） | 前置依赖 | 本周产出物 |
| --- | --- | --- | --- | --- |

| W2 | SQL进阶 | 能 GROUP BY/COUNT/JOIN；窗口函数入门做简单排名 | W1 | 多表关联报表 + 工单状态分布 |

## 每周展开

### 第1周｜闭环意识 + SQL入门

- **目标**：建立「我在做什么」的地图；第一次从「表」里把需要的行取出来。
- **前置**：无（零基础）。
- **模块**：M00 → M01 → M02 → M03
- **产出物**：
  1. 一张手绘/文字版「最小闭环六步图」
  2. 针对 `tickets` 样本表的 3 条有效查询结果（含筛选与排序）
- **详细**：`weeks/W01_第1周.md`

### 第2周｜SQL进阶（聚合与关联）

- **目标**：从「查出几行」升级到「汇总成报表」和「两张表拼起来看」。
- **前置**：M02、M03 过关。
- **模块**：M04（GROUP BY/COUNT/JOIN/窗口入门）
- **产出物**：工单状态分布表 + 客户-工单关联查询

### 第3周｜Python基础语法

- **目标**：把「字段值」当成可编程对象；写可重复执行的小函数。
- **前置**：理解表/字段（M01）；不要求会JOIN。
- **模块**：M05、M06
- **产出物**：`clean_ticket.py`（清洗文本、判断紧急度关键词）

### 第4周｜pandas + API + JSON

- **目标**：从CSV批量取数，调用AI/业务API，解析返回的JSON。
- **前置**：M05、M06
- **模块**：M07、M08
- **产出物**：`batch_classify.py`（读CSV→调API→写回结果CSV）

### 第5周｜Linux排障 + Docker + API边界

- **目标**：服务挂了能「看日志、找进程、查端口」；能 `docker run`；理解Webhook/验签/幂等。
- **前置**：M08（会发HTTP请求）
- **模块**：M09、M10、M11
- **产出物**：容器启动记录 + 一次失败排查笔记

### 第6周｜RAG

- **目标**：FAQ知识切块→检索→生成；会用Groundedness/Relevance做人工抽检。
- **前置**：M07、M08
- **模块**：M12
- **产出物**：售后政策问答最小RAG + 10条人工打分表

### 第7周｜Agent + Eval

- **目标**：定义工具与参数；设定「必须人工确认」的动作；建Golden Dataset并算Precision/Recall。
- **前置**：M12
- **模块**：M13、M14
- **产出物**：工具调用流程图 + 20条Golden评测结果

### 第8周｜最小闭环总装

- **目标**：独立串联取数→处理→AI→呈现→反馈→记录；用有分母方式写效果。
- **前置**：W1—W7 核心卡片过关。
- **模块**：M15、M16
- **产出物**：可演示项目包 + 《效果报告（含分母）》
