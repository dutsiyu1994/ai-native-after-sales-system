## 0.1 适用对象

- 完全零基础、不懂编程的成人学习者。
- 有业务运营 / AI 应用落地经验（例如做过流程SOP、提示词、规则配置、效果汇报；行业不限）。
- **SQL、Python、Linux、Docker、API 均为零基础**。
- 每天可投入 **20—60 分钟**，总周期 **8 周**。

不适合：需要立刻上生产改库、写复杂后端系统的工程师速成班（本课程目标是「最小闭环」，不是全栈工程师）。

**重要**：本课程**不以售后/客服为业务锚点**。客服工单仅作为默认**学习案例**；能力目标可迁移到订单、线索、审批、风控等任意业务。详见 [meta/案例场景使用约定.md](./meta/案例场景使用约定.md)。

## 0.2 使用方式（知识库 / 学习平台）

1. **按周学**：打开 `weeks/W0X_*.md`，按当日建议卡片完成。
2. **按模块复用**：其他课程可直接引用 `modules/MXX_*.md` 中带 `#可复用` 的卡片。
3. **按标签检索**：用 `#SQL` `#RAG` 等标签筛选原子知识点。
4. **按前置依赖编排**：每张卡片有 `前置知识` 字段；平台可画依赖图。
5. **按掌握标准过关**：每张卡有「能做到什么才算过关」；过关后再进入下一张。
6. **练习 → 项目 → 评估**：每周有最小练习、综合练习、可展示产出；第8周做完整闭环项目。

## 0.3 假设清单（信息不足时按此生成，不反问）

| 假设ID | 假设内容 | 影响范围 |
| --- | --- | --- |
| A01 | **默认学习案例**为「客服工单 / 客户主数据」（可替换）；课程能力目标不绑定售后行业 | 示例叙述与 `assets/samples/` |
| A02 | 取数练习优先用 **SQLite**（一种轻量本地数据库，数据存在一个文件里）或在线 SQL 演练场；不要求公司数仓账号 | M01—M04、项目 |
| A03 | Python 使用 **3.11+**；若本机安装困难，可用 Google Colab 或同等在线 notebook | M05—M08 |
| A04 | AI 调用使用 **OpenAI 兼容接口**（如 DeepSeek）；密钥由学习者自备，示例用占位符 `YOUR_API_KEY` | API/RAG/Agent |
| A05 | 操作系统命令以 **Linux/macOS 终端** 为准；Windows 用户使用 WSL2 或 Git Bash（命令差异在卡片「常见错误」说明） | Linux 模块 |
| A06 | Docker 使用 Docker Desktop 或等价环境；第5周才要求安装 | Docker 模块 |
| A07 | 「最小闭环」定义为：取数→处理→调用AI/API→结果呈现→人工反馈→效果记录；不要求上线生产、不做高并发 | 全课程目标 |
| A08 | 每天有效学习 20—60 分钟；每周约 5 个学习日 + 1 个复习/项目日 | 时长设计 |
| A09 | 所有示例数据为虚构脱敏样本，可随仓库分发；学习者可用自有脱敏表替换同构字段 | `assets/samples/` |
| A10 | 评估采用「有分母」描述（例如 20/20 条人工核对正确），禁止只说「效果很好」 | Eval 体系 |
| A11 | 课程中文为主；代码标识符可用英文（行业惯例），卡片内逐行中文注释 | 全部代码块 |
| A12 | 综合项目以「最小闭环可演示」为准；若环境中有现成 Demo 应用，仅作可选参考，不要求也不绑定售后产品形态 | 综合项目 |
| A13 | 卡片中的「学习案例对应」默认写工单故事，并鼓励映射到读者真实业务 | 全部知识点卡 |

## 0.4 核心术语（第一次出现的一句话解释）

| 术语 | 一句话解释 |
| --- | --- |
| FDE（前沿部署工程师） | 把 AI/数据能力「部署」到真实业务现场、跑通闭环并持续改效果的人，不只写演示 PPT。 |
| 最小闭环 | 从取数到反馈记录能完整走通一遍、可重复执行的最短流程。 |
| 知识点卡片 | 可独立学习、独立评估、独立复用的最小内容单元，带唯一 ID。 |
| 前置知识 | 学本卡片前必须先过关的其他卡片/模块。 |
| 复用标签 | 方便其他课程检索、引用本卡片的关键词标记。 |
| RAG | 检索增强生成：先查资料再让 AI 回答，减少瞎编。 |
| Agent | 能按任务选择并调用工具（查库、发请求等）的 AI 工作流。 |
| Eval | 用固定样本和评分标准，客观衡量系统好不好。 |
| 有分母的效果描述 | 必须写成「正确数/总数」或「命中数/应命中数」，不能只说形容词。 |
