# 5. 练习与项目体系

**设计原则**：每个阶段 = 1个最小练习 + 1个综合练习 + 1个可展示产出。  
练习必须可在约定时间内完成；项目强调「能给别人看」。  
**案例原则**：下列练习默认用客服工单样本；若你改用订单/线索等数据，只要字段同构、掌握标准不变，即视为同一练习。

## 5.1 第1周（已展开）

### 最小练习 EX-W01-MIN

| 字段 | 内容 |
| --- | --- |
| 练习ID | `EX-W01-MIN` |
| 名称 | 取出所有高优先级工单 |
| 对应卡片 | `KP-M03-01` |
| 时限 | 15—20 分钟 |
| 任务 | 对 `tickets` 写出SQL：选出 `priority='高'` 的 `ticket_id, subject, status` |
| 提交物 | SQL原文 + 结果行数 |
| 通过标准 | SQL可运行；结果行数与样本一致（样本中高优共9行：T1001,T1002,T1006,T1008,T1010,T1013,T1016,T1018,T1020） |

### 综合练习 EX-W01-INT

| 字段 | 内容 |
| --- | --- |
| 练习ID | `EX-W01-INT` |
| 名称 | 值班加急池清单 |
| 对应卡片 | `KP-M03-02` `KP-M03-04` `KP-M03-05` |
| 时限 | 30—40 分钟 |
| 任务 | 条件：`(priority='高' OR status='升级') AND status not in 已解决/已关闭`；按 `created_at ASC`；`LIMIT 8`；列需中文别名 |
| 提交物 | SQL + 结果表 + 2句策略说明（为何ASC、为何OR） |
| 通过标准 | 条件与排序正确；能口头讲解给非技术同事 |

### 可展示产出 PRJ-W01-01

| 字段 | 内容 |
| --- | --- |
| 项目ID | `PRJ-W01-01` |
| 名称 | 《高优先级事项Top5清单》一页纸（默认案例：工单） |
| 时限 | 40—60 分钟 |
| 交付结构 | ①业务问题一句话（可写你的真实业务） ②闭环六步中「取数」如何服务后续步骤 ③SQL ④结果 ⑤若把该清单交给AI分类，应SELECT哪些列（最小字段） ⑥一句话说明：若换成订单/线索，表与字段如何映射 |
| 展示对象 | 假设给业务负责人看（行业自选） |
| 评分 | 见 `06_评估体系.md` 中 `RB-W01-PRJ` |
